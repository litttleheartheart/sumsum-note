# 第一章　沒人舉報的夜

爐火只剩一層紅。窗縫漏進一點夜氣，木味、乾皮、還有托帕藏過肉乾的味道。涼意貼着將要裸出來的後頸走。

伊得睜着眼。

身旁那具一百九十公分的身體佔去大半張床。呼吸極長，長到他能在兩次起伏中間把自己的心跳數完。褐金的髮被什麼小動物拱亂過，幾綹貼在額上。眉是平的。唇微開。眼下那兩道青黑在暗裡仍清楚——洗不掉，只是這次沒有壓着看人。

他只穿一件極寬的薄麻單衣，領口拉得很低，沒有鈕扣，一根繩結鬆垮垮繫在鎖骨下。下身是同樣寬鬆的長褲。體溫太高，薄麻被淺淺汗濕，隱約貼出深色胸溝——胸大肌邊緣連向肋骨的那道凹，隨極長的呼吸像沉地一樣微微張合。腹上六塊縱橫的形被歲月夯過，人魚線向褲頭深處收，溝裡一條淺汗，閃着濕光。寬袖口外露出小臂，青筋如樹根盤着。領口敞開處，斜方肌一路鋪到肩頭。睡着也不肯把人包嚴。

睡着的崑西不看獵物。

白天那張只需壓低眉骨就能讓人腿軟的臉，此刻毫無防備地擱在枕上。伊得看了兩秒，心裡那點被「麻煩」打發的賭氣，慢慢變成另一種更私的東西：這具身體現在誰都不能搶。

「……真的假的。」他把聲音壓進氣裡，幾乎是貼着那截耳廓吹過去的濕氣，「白天說麻煩，晚上睡得比樹還死。」話音剛落，下唇被自己咬出一道淺白。

枕邊一雙圓眼睛亮了一下。托帕蹲在他肩能摸到的距離，鼻子動了動。

伊得豎起一根手指，比了個噤聲。

白鼬看他，又看那截沉睡的頸側，然後「吱」得極輕，跳上樑。木頭響了一聲。再然後，小屋裡只剩兩種呼吸。一種慢。一種已經亂了。

伊得跪到床沿。

他先沒有伸手。近到能數清對方睫影，才發現這張臉在醒着時從來沒有這麼平——眉骨還在，獵意不在。鼻腔裡砸出來的熱氣直接打在他唇齒上，日曬過的木、乾皮、濃得發沉的雄性氣味。每吸一口，喉嚨與下腹就空一分。青黑像誰用炭灰抹過，睡着也不肯淡。原來不看人的時候，是這張臉。

指腹碰上去的瞬間，他自己屏住氣。

指尖偏涼，夜氣又舔過一層。貼上那張滾燙的臉時，皮膚發緊，像冰碰到鐵板。顴骨不是軟肉，是轉折極深的骨。青黑那塊皮更薄，指腹能隱約摸到眼眶下緣的凹，底下有極細的脈在跳——活過很久的痕跡，溫的，不是灰。額角與鬢有一層淺淺的汗氣，抹過，熱濕就沾在他自己指尖上。

拇指不小心擦過下唇乾裂的小口。想用舌去舔開那道乾痕的念頭來得很快。口腔立刻多餘地分泌，咽喉反而發乾。白天不讓多碰，現在這張嘴微啟着，像任他處置。

崑西的眉淺淺皺了一下，又散開。呼吸仍長。下顎線旁那一點粗糙的茬，刮得伊得指腹發麻。

「……睡着比較好說話。」他幾乎沒出聲。

手往下滑。指尖點過喉結時，那東西滾了半寸。兩側頸肌即使在深睡裡也寬、沉，包着那截喉。指尖稍用力，粗大的脈在皮下緩慢、強勁地搏。伊得整個人僵住——以為醒了。

胸腔深處滾過一聲極低的喉音，不是話，是夢的邊角被誰拱了一下。熱氣同時砸在他臉上。

下腹狠狠一酸。腿軟了半拍。

下一拍，氣還是從極深的地方慢慢上來。不是醒。只是睡裡一次極慢的吞嚥。

他才敢再往下。

指尖先碰到領口那根鬆垮的繩。沒解，只從領口鑽進去。粗糙麻布擦過胸肌與深色皮膚，沙沙一聲，在靜得能聽見樑蟲的小屋裡長得刺耳。伊得心跳猛地搶拍，手停在布與肉之間，等了半息——呼吸仍長。

才把掌妥帖地覆上胸膛。

手掌被那層厚實微微撐開。白而窄的指覆在深色的胸上，差了一整個號。熱，沉，帶着體溫，不是石頭——要兩隻手才挪得動這種睡着的重量。汗濕的薄麻被他的手撐離皮膚又貼回去，胸溝的形在布下一下清楚、一下模糊。肺部張合帶着整個胸廓起落，心跳隔着皮肉一下一下撞過來，慢得像另一個季節。不是白天把人擠在樹與胸之間的那種硬。乳尖在熱皮膚上只是微微的一點；指腹一過，胸肌無意識抽縮一瞬，青筋在深色皮下微隆，單衣跟着那一下輕輕一顫，隨即又鬆。伊得心跳漏了一拍。沒停。指腹沿着胸口那道溝繼續走，麻布一寸寸被拱起來，沙沙聲跟着他的手往下。

「這肩跟這胸到底吃什麼長大的……」心裡罵，沒出聲，「社畜天天坐辦公室，連人家一半都沒有。」

溝在呼吸裡一會兒淺、一會兒深。腹往下，手越低，小屋越靜。即使沒發力，那層被歲月夯過的腹仍有密度，熱得發燙，薄麻被汗貼在溝上，像故意把形交出來。近胯處那一塊即使沒繃也擱在那裡，人魚線向褲繩深處收緊。被單從那裡開始隆起，隆起底下是褲頭那根還沒解的繩——布被頂出一塊誇張的形，一跳一跳。伊得的腕發緊。前端已經把布料頂起來，他還是先沒去管自己。

「白天穿得規規矩矩說麻煩，睡着了這身肉簡直比武器還過分……這份量到底藏在哪裡的。」

掌隔着被單與褲布覆上那塊隆起。

底下跳了一下。高熱隔着布燙進掌心。單手包不住。胯間那股日曬木味疊上一點發酸的前液氣味，在這間靜得能聽見樑蟲的小屋裡被放大。唾液過多，口渴得發疼。上方那張臉眉眼仍平，褲布下那頭卻聞着味想伸頭。

人沒醒。巢裡那頭先換了氣。

他俯近。鎖骨下的契約石隱隱發燙，隔空去嗅右手背上那顆黃玉——還沒亮透，已經在扯。體內湧起一截空，黏膜自己先知道：碰上去，熱才會過來。

掀開被單。

滾燙的熱浪先衝到臉上與掌心，指尖那點涼氣一瞬間蒸成汗。手抖着去解褲頭的繩結。結因睡姿壓得緊，指尖在粗糙麻繩上滑了兩次才扯開。寬褲沿人魚線往下滑。包裹着的那團沉甸甸、發着高熱的東西「啪嗒」彈出來，褲布刮過還沒完全抬起的冠溝，帶出一圈透明水光。沙沙，隨着布退下，像誰把最後一層也拆了。

深褐近赭的性器垂成一道有重量的弧。軟着，已經有驚人的長與粗。頭是深赭，冠溝深而寬，一圈粗糙的環，因熱與前液繃着濕光，沉得像鈍刃。柱身青筋如老樹根凸在深褐皮上，脈一下一下。下方囊袋沉，滿着熱，壓在股根，雄性氣味與日曬木味蒸上來。腿間的毛、深色腿根、這根擱在毛皮上——小鬼把手伸進了獵手的巢。

伊得把多餘的唾液咽下去，掌覆上去。單手扣不合。改用雙手去托，才勉強抬起這截帶密度與體溫的沉。指節發白，淺色貼着深褐。根連着那條硬熱的人魚線。光用手指量，就能想像待會頂進來時，自己小腹會被頂成什麼形。

空氣與掌心的熱一激，內部的脈像火種。青筋一抖一抖充血，它從重軟裡抬高，在眼前硬生生大一圈。鈴口微張，黏液拉絲從冠溝溢下，沿柱身滑進腹溝，滴進被單。

「這份量……白天到底藏在哪裡啊。」心裡罵，「社畜加班是消耗生命，這傢伙光是這根就頂得上別人兩條命。」「主人睡得像截枯樹，養的這頭凶獸倒是聞着味就醒了。」待會兒要用嘴，甚至用後面，把它整根吃進去——恐懼和興奮一起把唾液逼出來。

他把那件單衣一路撩到胸口。薄麻褶皺堆在寬厚肋骨兩側，領口敞着，兩塊高聳的胸與微發硬的乳尖被涼空氣咬住，半遮半掩，像被強制剝開卻還沒剝完。長褲褪到膝彎，沒全脫。凌亂擱在沉睡的身體上。

「人睡死了。」他幾乎沒出聲，「你倒挺精神。」

沒有回答。當然沒有。胸膛仍按那種慢節奏起伏，喉結安安靜靜地擱在頸側——剛才滾過的那一下，像沒發生過。伊得俯下去，先碰到的是皮膚的熱，然後是冠溝——深的一環，前端自己亮着一圈水，還在脹，已經不好含。褲布剛刮過的那圈水還亮着。

舌尖貼上那道溝的時候，脈從根部走上來，凹槽底下的血管像活物。

崑西的眉心淺淺皺了一下。只一下。呼吸斷半拍，又接回去，比剛才短了少許。伊得眼睫一顫，沒停。他盡量把嘴張到最大，唇角發白發酸，兩頰被撐薄，幾乎能從外側看出柱身的輪廓。犬齒與唇沿繃開，生怕蹭到冠溝下緣。也只含進前端與那圈最寬的環。冠溝把舌面整塊壓平，邊緣刮過上腭，麻，脹。小心翼翼地退，再含深一點。唾液立刻被那截高熱蒸得不夠用，他只好自己吞吐出更多津液去裹。水聲細碎：哧哧，咕唧。疊着剛才麻布的餘響，在樑下迴一圈。每響一聲，後頸死死繃緊，耳根與後頸就紅一分——樑上有托帕，身下這個人隨時會睜眼。

它在口裡脹，變沉，抬起來。青筋一跳一跳擴張，熱鐵似的把僅剩的氣擠乾。舌根發酸。口腔被填滿。白天裝得一派清心寡慾，底下養的這根倒誠實，聞着味就往嘴裡塞。這份量……真是要命。社畜加完班還要用嘴伺候這種凶獸。

伊得的眼眶發熱，仍把聲音全咽回去。退出半寸換氣時，兩人體液在唇齒間拉出數條細密發亮的銀絲，「啪嗒」斷在深褐柱身上，皮更油、更燙。急喘噴在發燙的陰毛與柱身上；崑西偶爾砸出的深息，反過來拂過他發紅的眼角。堆在肋骨上的單衣隨着胸廓微微滑，又沙一聲。

「醒了再算帳。」他含糊地說，字被粗碩擠在喉深處，黏着噴在發硬的下腹與陰毛上，「醒、醒了再算……嗯唔……這次沒人舉報。」

又跳。比剛才清楚。前液與唾液在唇邊混成黏絲，沿深褐的莖往下，滴進腹溝，再滴進毛皮，也滴在堆開的麻布邊。

無意識的手落下來。

比他半張臉還寬的掌按在他後腦。不是推開。是按住。指節陷入淺棕軟髮，掌上的繭摩擦後頸嫩皮，像捏住小動物的後頸。力道已經很大，人卻還沒把眼睜開。頸椎發麻。伊得被按着含深，冠溝頂開喉口，窒息，乾嘔痙攣一縮，生理性的水湧上眼睫，想咳，只能把咽音死死塞回喉裡。想退，掌沒鬆。冠溝卡在唇沿，前液又亮一圈。

本想趁睡私佔這具平時碰不得的身體，結果自己變成被按在胯間挨塞的東西。身份一翻，恥和興奮一起湧上來。

胸腔裡又滾過半截極低的氣。低頻震過胯骨，震進貼着他的頰，耳膜發鳴。腹肌無意識發硬一瞬，六塊如石，人魚線深陷，堆在肋上的單衣被那一下頂出更清楚的溝。胯微微上抬，把那根更深地送進喉口。不是話。像夢的邊角被誰拱了一下。腿根蹭到的大腿外側，熱，沉，不可撼，像熟鐵。

鎖骨下的霓虹石因近處那顆黃玉而微熱，隔着薄衣悶出一點暗紅。黏膜空、酸、麻，要熱，要水。

伊得的前端硬着，吐着水光，隔着自己還沒褪盡的布在崑西大腿外側蹭了一下——那層粗熱的皮像磨石，頂端一刮，他幾乎要提前交代。立刻停住。水聲在這麼安靜的屋子裡會變得很響。他一隻手死死扶着嘴裡那根高熱，另一隻手狼狽去解自己的腰帶。指尖抖，又沾了前液，在扣上滑了兩次才解開。褲子褪到膝彎，沒全脫。窗縫的夜氣立刻咬上赤裸的後背與膝彎，涼得刺骨，背脊一顆顆雞皮起來。嘴裡卻含着熔岩。冰火一疊，下腹敏感翻倍。另一隻手仍扶着那根已經完全醒過來的東西：沉甸甸立着，顏色深，青筋盤着，頂上掛着他的唾液和它自己的水。

人還閉着眼。

只有腹下這頭先換了氣。

伊得抬起腰。手指伸到身後。自己擴。近着這具身體，黃玉的熱浪往皮膚裡滲，黏膜像開了閘，渴望被填、被燙平。濕得太快。兩指進去時嚓哧、咕啾，黏液被絞成細沫，在空樑下迴了一圈。指節與穴口之間拉出數條又亮又韌的銀絲，斷開，「啪嗒」砸在那層高熱硬實的腹上。他越怕屋頂響，水聲因緊張與體溫越響。每一聲都像在宣告他正在做什麼。耳根燙得要滴血。死死咬住下唇，咬出白痕，把那聲咽成鼻音：「唔……嗯哈……」急喘噴在發燙的胸與腹上。穴口在涼空氣裡縮，褶皺發緊，體內卻燙。懸空的臀被夜氣吹着發抖。透明的水沿着指節往下，滴在崑西小腹的溝裡，亮了一點，也把撩高的單衣下擺洇出一大片暗痕，薄麻黏在深色腹上。

明明平時累得像條狗，這種時候身體倒比誰都誠實……才摸了幾下就濕成這樣。怕吵醒樑上的托帕，也怕吵醒身下這個人，可騎在沉睡的獵人身上做這事的禁忌，又讓後穴把手指絞得更緊。指節已經填不滿那截被魔力掏空的酸。

他跨上去。膝陷進毛皮。要分開那條沉睡的腿時，才真切感到——不是石頭，是帶體溫的沉，兩手才能稍稍推動。長褲還掛在對方膝彎，布邊磨着他的小腿。白而窄的大腿內側死死繃着，抖，膝彎發軟，細腰用力凹出一道弧。臀與腿外側擦過對方粗熱的腿——磨石一樣燙着發抖的腿根。對準的時候手抖。

頭比他此刻張開的縫更大。深赭的冠溝抵上來，環又寬又硬。

「社畜加班也沒……這麼——」

話沒說完。他往下坐。卡住。最寬那一圈把褶皺撐到近乎透明發白。鈍痛，飽脹。雙腿張得更開，懸在空中抖，扭腰讓水再潤滑一分，那圈冠溝才「咕唧」一聲、痛苦地凹進去。停半息。熱從那個接觸點鑽進來，比口裡含着時更清楚，像要把內壁熨平。窗外涼，裡面燙。

他吐氣，再沉一寸。青筋如樹根擦過黏膜。軟肉無意識絞緊，反而把這根熱鐵咬死。每半寸，體內空氣都被擠掉，像要裂。哧咕、哧哧，擴張留下的水與前液被一點點擠出，沿腿根與柱身淌下，拉出極長的銀絲。前半濕，後半緊。平坦白皙的小腹開始被頂起一塊不該在睡着的人身上出現的弧——誇張，硬，滾燙，連內裡被向上推的悶都能感到。堆在崑西肋側的麻布被他的腿根擠得更皺。

吃到極限。酸脹到再進一絲都沒有。低頭看：胯間竟還剩兩三指寬的深色柱身露在外面，根部青筋盤着，高熱的囊袋沒能貼上臀。已經撐滿，外頭卻還有一截。那截懸在夜氣與體熱交界，掛着唾液與前液，蒸着淡熱氣，隨他喘息一跳一跳。

「這到底是吃什麼長大的……太誇張了……我都已經撐爆了，怎麼還剩這麼長……」要把這種東西全部吃進去，簡直比加班跑全場還命苦。白天裝得清心寡慾，底下這根根本想把人從中間劈開。契約石卻因柱身傳進來的黃玉熱而燙得要融。深處叫着還要，身體說吞不下。

他只能退半寸，再進三分。每一次都麻到腳趾。白皙大腿死死夾住對方粗熱的外側，懸着腰抖，膝彎要滑。崑西的腹與人魚線因被極致包裹而無意識發硬、繃緊，腿肌隆起，把人擠得更死。

崑西的眉又皺了。喉結滾過。按在他後腦的那隻手早已滑下來，落在腰側，還沒扣死，只是擱着，像還沒決定這是不是麻煩。指節卻因被咬緊而微微陷進發抖的腰肉，無意識往下帶了幾毫米。伊得差點叫出聲，咬破下唇也擋不住喉深處擠出來的黏音：「嗯……唔哈……太大了……吞不下……」噴在發燙的胸膛上。

囊袋沒能拍上臀。可扎在裡面的那截青筋已經貼着腸壁的脈。兩人小腹同時發燙。黃玉與契約石悶悶亮了一下，微光從衣縫照着那截還露在空氣裡的深色柱身。弧底下那條青筋一跳一跳，把另一個人的脈直接傳進他體內。

他沒忍住。

那一聲漏出來，短，濕，疊上黏液被擠出的哧聲，在小屋樑下彈了一下。

「……哈。」

崑西的呼吸斷了。

不是睡眠那種接不回去的斷。是從極長的起伏裡被誰拽出來的、短的兩截。貼着的胸口裡，那顆極慢的心忽然沉、重、密，一下一下砸進伊得的骨，震到脊髓——睡眠的季切斷了，換上獵手的拍。被他坐着的腹驟然繃成熟鐵，臀下那層沉變成不可撼的硬。胸大肌與斜方肌一脹，堆在肋側的薄麻繃緊，散開的領口徹底張開，深色皮膚上蒸着他的汗，發亮。粗壯的大腿內側一收，像夾子鎖住他發抖的腿根。想抬，退路沒了。

扎在體內的那半截同時二次充血。樹根似的青筋一抖、一抖，黏膜被脹得發麻，別人的脈在最裡面砸。露在外面那截又硬抬半寸，滾燙抵進更深的一點，小腹那塊弧更誇張。更稠的前液湧出，與他的水混在交界，毛皮上一片黏光。

汗濕的單衣還堆在他肋骨兩側，領口繩結早不知在哪一下裡散開了。

睫顫了兩下。眉心皺得更緊。縫裂開一條。暗橘在黑暗裡因熱與光而微縮。焦距從渙散往眼前聚——發抖的、眼角帶淚的、正把這根深色粗碩吞了一半、外頭還沾着自己唾液的人。視線從濕紅的眼角、咬破的下唇，滑到交界。第一口極沉極熱的氣噴在發紅的鎖骨與頸上，汗與木味像鎖。

玩大了。這下真要把命賠給這頭凶獸了。想退退不掉，想進進不去。白天惹他麻煩，現在還把他下半身當玩具偷吃——等這頭完全醒，會被從頭拆到尾。

「崑、崑西……」解釋卡在嗓子眼，出來的是帶哭腔的氣，被裡面那一下脈衝撞成斷續的哼。

扣在腰側的五指先收緊了。厚繭陷入白而窄的腰，拇指按上腰窩與骨盆，指節發白，淺色皮膚上烙出紅白交織的印。掌心一揉一按，把那點發抖想喘的縫硬往下送。「咕唧。」卡在半途的那截又被推進半寸。尖叫堵回喉裡。

胸腔深處滾過一聲極低、極啞的醒轉。不是白天那種懶的「麻煩」。是被偷吃之後，還沒開口的、帶熱的東西。

想抬，抬不動。
